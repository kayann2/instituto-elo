# Instituto Elo

Site conceitual de uma clínica fictícia de terapia de casal e vínculos, criado para portfólio. As pessoas, a clínica e as informações de contato são fictícias. As imagens foram geradas com IA.

## Executar localmente

Com Node.js 18 ou superior, execute `node server.js` e acesse http://localhost:3000. Não há dependências para instalar.

O site usa HTML, CSS e JavaScript, com órbitas em WebGL e uma sequência de imagens controlada pela rolagem. Há uma alternativa estática para quem prefere movimento reduzido.
